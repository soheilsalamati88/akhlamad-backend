# راه‌اندازی بک‌اند سایت اخلمد (پیامک واقعی + پرداخت واقعی)

چون سرور ندارید، ساده‌ترین مسیر استفاده از یک سرویس PaaS رایگان مثل Render است؛
نیازی به مدیریت سرور، لینوکس یا SSH نیست.

## مرحله ۱ — ساخت حساب کاوه‌نگار (پیامک)
1. در kavenegar.com ثبت‌نام کنید و اعتبار اولیه بخرید.
2. از پنل، مقدار API Key را کپی کنید.
3. در بخش «اعتبارسنجی» یک الگوی OTP بسازید (مثلاً به نام verify-akhlamad) با متنی شبیه:
   کد ورود شما به اخلمد: %token%
   تأیید الگو معمولاً چند ساعت طول می‌کشد.

## مرحله ۲ — ساخت حساب زرین‌پال (پرداخت)
1. در zarinpal.com ثبت‌نام کنید (نیاز به شماره شبا و مدارک هویتی دارد).
2. تا زمان تأیید نهایی، می‌توانید با «سندباکس» کل مسیر پرداخت را بدون پول واقعی تست کنید.
3. بعد از تأیید، Merchant ID واقعی را در تنظیمات محیطی بگذارید و حالت سندباکس را خاموش کنید.

## مرحله ۳ — دیپلوی روی Render
1. حساب بسازید در render.com (می‌توانید با همان حساب گیت‌هاب وارد شوید).
2. New را بزنید و Web Service را انتخاب کنید.
3. ریپوزیتوری akhlamad-backend را وصل کنید.
4. Runtime را Node بگذارید، Build Command را npm install و Start Command را node server.js بگذارید.
5. در بخش Environment، کلیدهای لازم (کلید کاوه‌نگار، نام الگو، مرچنت آی‌دی زرین‌پال، آدرس سایت) را وارد کنید.
6. Create Web Service را بزنید.

## نکات امنیتی مهم
- کدهای OTP و نشست‌ها فعلاً در حافظه سرور نگه‌داری می‌شوند؛ برای پروژه واقعی و پرترافیک بهتر است این بخش را با یک دیتابیس جایگزین کنید.
- هرگز کلید کاوه‌نگار یا مرچنت آی‌دی زرین‌پال را در کد سمت کاربر (HTML) قرار ندهید.
- قبل از رفتن به حالت واقعی، حتماً کل مسیر را در سندباکس تست کنید.
